## 项目简介

Visual Tension 半自动图像标注工具是一个专为训练 Stable Diffusion LoRA 模型而设计的桌面应用程序。该工具结合了人工标注和 AI 自动标注功能，帮助用户高效地为建筑图像生成准确的标签数据集。

## ✨ 主要特性

### 🖼️ 智能图像处理
- **多格式支持**：PNG, JPG, JPEG, WEBP, BMP, GIF 等常见图像格式
- **智能裁剪**：支持多种比例裁剪（4:3, 16:9, 1:1, 3:2, 2:3）和自由裁剪
- **自定义比例**：可输入自定义长宽比例进行精确裁剪
- **实时预览**：可视化裁剪框，支持拖拽调整位置和大小
- **🆕 分辨率检查**：自动检测裁剪后图片短边像素，低于768像素时智能提示
  - 提供三种选择：继续使用、跳到下一张、重新裁剪
  - 帮助确保训练数据质量

### 🏷️ 智能标注系统
- **人工标注**：基于建筑视觉张力理论的分层标签体系
  - **空间感知（人可停留）**：无灰空间、空间边界处理
  - **界面感知（人可看见）**：通透程度、开口密度
- **AI自动标注**：集成 GPT-4o API，基于专业建筑分析生成描述性标签
- **标签合并**：自动合并触发词、人工标签和AI标签为最终输出
- **实时预览**：标签选择即时显示在最终标签区域

### 💾 输出管理
- **智能分类**：根据选择的标签类型自动创建子文件夹
  - `spatial_perception_only/`：仅空间感知标签
  - `interface_perception_only/`：仅界面感知标签
  - `spatial_interface_both/`：两种标签都有
  - `other/`：其他标签
  - `no_tags/`：无人工标签
- **双文件输出**：同时保存标签文件(.txt)和对应的图像文件(.png)
- **UTF-8编码**：确保中英文标签正确保存

### 📊 运行统计功能
- **🆕 自动统计**：实时记录标注进度和标签使用情况
  - 处理图片总数
  - 每个标签的使用次数和百分比
  - 各分类文件夹的图片分布
- **🆕 详细报告**：自动生成可读的统计报告
  - 保存位置：`输出文件夹/statistics/`
  - JSON格式数据：`labeling_statistics.json`
  - 文本格式报告：`labeling_report.txt`
- **会话统计**：统计本次运行期间的所有操作

### 🔧 用户体验优化
- **🆕 操作引导**：智能提示系统，防止误操作
  - 裁剪状态实时提示
  - 未应用裁剪时的友好提醒
- **快捷键支持**：
  - `←` / `→` 上一张/下一张
  - `Ctrl+S` 保存
  - `Ctrl+Enter` 保存并下一张
- **进度显示**：实时显示当前图片序号和总数
- **配置持久化**：API配置和Prompt自动保存

### 3. 基本使用流程

#### 步骤1：配置触发词和API（可选）
1. 在右侧顶部紫色区域输入项目触发词（默认：archtensionstyle）
2. （可选）在"API配置"区域输入 OpenAI API Key
3. 点击"💾 保存配置"

#### 步骤2：加载图像
1. 点击左侧"📁 选择图片文件夹"
2. 选择包含待标注图像的文件夹
3. 使用"← 上一张"/"下一张 →"按钮或键盘方向键浏览

#### 步骤3：裁剪图像（可选但推荐）
1. 选择裁剪比例（默认4:3，推荐用于训练）
2. 拖动绿色裁剪框调整位置和大小
3. 点击"✂️ 应用裁剪"
4. 💡 如果短边<768像素会弹出警告，可选择：
   - ✅ 继续应用：接受当前裁剪
   - 🔄 重新裁剪：调整裁剪区域
   - ⏭️ 下一张：跳过当前图片

#### 步骤4：人工标注
1. 在中间面板勾选相应的标签
   - **空间感知（人可停留）**：无灰空间、界面退让、悬挑覆盖、街道外摆、空间折叠
   - **界面感知（人可看见）**：界面通透程度和面街开口密度
2. 可同时选择多个标签
3. 标签实时显示在右侧"最终标签"区域

#### 步骤5：AI辅助标注（可选）
1. 确保已配置 OpenAI API Key
2. 确认 API URL、模型、图像质量和超时时间
3. 点击"✨ 生成"按钮
4. 智能体按 11 标签闭集完成判断，并自动添加到最终标签

#### 步骤6：保存输出
1. 点击"📁 选择输出文件夹"（只需设置一次）
2. 检查"最终标签"文本框内容（可手动编辑）
3. 点击"💾 保存 & 下一张 →"
4. 图片和标签自动保存，跳转到下一张

#### 步骤7：查看统计（完成后）
1. 标注完成后，打开输出文件夹
2. 进入 `statistics/` 子文件夹
3. 查看 `labeling_report.txt` 了解标注统计

## 配置文件说明

### API配置 (api_config.json)
```json
{
    "api_key": "your-openai-api-key",
    "api_url": "https://api.openai.com/v1/chat/completions",
    "model": "gpt-4o",
    "quality": "auto",  // 图片质量：auto/high/low
    "timeout": 60       // 超时时间（秒）
}
```

### 标签字典

#### spatial_perception_dict.json - 空间感知标签（5 个）
包含两个二级分类：
- **无灰空间**：无灰空间
- **空间边界处理**：界面退让、悬挑覆盖、街道外摆、空间折叠

#### interface_perception_dict.json - 界面感知标签（6 个）
包含两个二级分类：
- **通透程度**：界面低通透、界面半通透、界面高通透
- **开口密度**：面街开口少、面街开口中、面街开口多

### Prompt配置 (prompt_config.json)
包含智能体启用开关、角色定义、11 标签判定细则、互斥规则和严格输出格式。

## 常见问题

### Q: 启动失败或闪退？
A: 请检查：
1. Python版本是否为3.8或以上
2. 是否正确安装了所有依赖库
3. 查看控制台/终端的错误信息
4. Windows用户确认安装Python时勾选了"Add Python to PATH"

### Q: API调用失败？
A: 请检查：
1. OpenAI API Key 是否正确且有足够余额
2. 网络连接是否正常
3. API URL 是否正确（默认官方地址）
4. 尝试增加超时时间设置

### Q: 图像无法加载？
A: 请确认：
1. 图像格式是否支持（PNG/JPG/JPEG/WEBP/BMP/GIF）
2. 图像文件是否损坏
3. 文件路径不含特殊字符或过长
4. 文件权限是否正常

### Q: 裁剪后提示分辨率过低？
A: 这是正常的质量检查：
- 建议训练数据短边≥768像素
- 可选择：继续使用、重新裁剪或跳过
- 尝试裁剪更大的区域以提高分辨率

### Q: 如何自定义标签？
A: 编辑JSON配置文件：
1. 打开 `spatial_perception_dict.json` 或 `interface_perception_dict.json`
2. 按照现有格式添加新的标签
3. 包含 `tag_en`（英文）、`tag_cn`（中文）、`description`（描述）
4. 重启程序生效

### Q: 统计报告在哪里？
A: 统计报告自动保存在：
- 位置：输出文件夹/statistics/
- 文件：`labeling_report.txt`（可读）和 `labeling_statistics.json`（数据）
- 每次保存图片后自动更新
