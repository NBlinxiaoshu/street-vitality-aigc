## 🎁 打包步骤

### 方法1：创建压缩包（推荐）

**Windows用户：**
1. 创建新文件夹：`Visual-Tension-Labeling-Tool-v1.2`
2. 复制所有必需文件到新文件夹
3. 右键文件夹 → "发送到" → "压缩(zipped)文件夹"
4. 重命名为：`Visual-Tension-Labeling-Tool-v1.2.zip`

**Mac用户：**
1. 创建新文件夹：`Visual-Tension-Labeling-Tool-v1.2`
2. 复制所有必需文件到新文件夹
3. 右键文件夹 → "压缩"
4. 生成：`Visual-Tension-Labeling-Tool-v1.2.zip`

**终端命令（所有平台）：**
```bash
# 在项目目录执行
zip -r Visual-Tension-Labeling-Tool-v1.2.zip \
  labeling_tool.py \
  requirements.txt \
  spatial_perception_dict.json \
  interface_perception_dict.json \
  prompt_config.json \
  start.bat \
  run.sh \
  install.py \
  README.md \
  快速上手指南.md \
  START_HERE.txt \
  LICENSE \
  项目清单.md
```

### 方法2：使用Git（开发者）

```bash
# 克隆仓库
git clone <repository-url>

# 或创建新仓库
git init
git add *.py *.json *.md *.txt *.sh *.bat LICENSE
```
