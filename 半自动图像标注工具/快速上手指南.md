# 📖 Visual Tension 图像标注工具 - 零基础快速上手指南

> 本指南专为没有编程经验的用户编写，用最简单的话告诉你如何使用这个工具。

---

## 🪟 Windows 用户使用指南

### 第一步：安装Python（只需一次）

**1. 检查是否已安装Python**
- 按键盘上的 `Windows键 + R`
- 在弹出的窗口输入 `cmd` 并按回车
- 在黑色窗口里输入 `python --version` 并按回车
- 如果显示 `Python 3.8` 或更高版本号，说明已安装，**跳到第二步**
- 如果显示"不是内部或外部命令"，需要安装Python

**2. 下载并安装Python**
- 打开浏览器，访问：https://www.python.org/downloads/
- 点击黄色的 "Download Python" 按钮下载最新版
- 双击下载的文件开始安装
- ⚠️ **重要**：勾选底部的 "Add Python to PATH" 选项
- 点击 "Install Now" 开始安装
- 等待安装完成（通常需要2-5分钟）

### 第二步：启动工具

**3. 双击启动（最简单）**
- 打开工具文件夹
- 找到 `start.bat` 文件
- **双击** `start.bat` 文件
- 第一次运行会自动安装必要组件（需要1-3分钟，需要联网）
- 等待程序窗口自动弹出

### 遇到问题？

**如果双击后没反应：**
- 右键点击 `start.bat` → "编辑"，查看是否有错误提示
- 或者右键 → "以管理员身份运行"

**如果提示"找不到Python"：**
- 重新安装Python，记得勾选 "Add Python to PATH"
- 安装完成后重启电脑

## 🍎 MacBook 用户使用指南

### 第一步：安装Python（只需一次）

**1. 检查是否已安装Python**
- 打开"启动台"（Launchpad），搜索"终端"（Terminal）
- 在终端窗口输入 `python3 --version` 并按回车
- 如果显示 `Python 3.8` 或更高版本号，说明已安装，**跳到第二步**
- 如果显示版本低于3.8或没有Python，需要安装

**2. 安装Python（如需要）**
- 打开浏览器，访问：https://www.python.org/downloads/
- 点击黄色的 "Download Python" 按钮下载Mac版
- 双击下载的 `.pkg` 文件
- 按照安装向导提示，一路点击"继续"和"安装"
- 可能需要输入Mac的密码
- 等待安装完成

### 第二步：启动工具

**3. 使用启动脚本**
1. 打开"终端"（在启动台里搜索）
2. 输入 `cd ` （注意cd后面有个空格）
3. 把工具文件夹直接**拖进终端窗口**，会自动显示路径
4. 按回车键
5. 输入 `chmod +x run.sh` 并按回车（只需要第一次运行）
6. 输入 `./run.sh` 并按回车
7. 等待程序窗口自动弹出

### 遇到问题？

**如果提示"权限不够"：**
- 在命令前加 `sudo`，例如：`sudo ./run.sh`
- 会要求输入Mac密码（输入时不显示，正常输入后按回车即可）

**如果提示"无法验证开发者"：**
- 打开"系统设置" → "隐私与安全性"
- 找到被阻止的程序，点击"仍要运行"

## 🎨 开始使用工具（详细步骤）

### 工具启动后的使用流程：

#### **第1步：准备图片**
- 把所有要标注的图片放在一个文件夹里
- 建议图片名称用英文或数字（避免中文和特殊字符）
- 支持格式：JPG、PNG、JPEG、WEBP、BMP、GIF

#### **第2步：加载图片**
- 点击左侧的"📁 选择图片文件夹"按钮
- 找到并选择你准备好的图片文件夹
- 第一张图片会自动显示在左侧
- 顶部会显示进度：图片 1/10

#### **第3步：裁剪图片（推荐但可选）**

**为什么要裁剪？**
- 训练AI模型时，图片尺寸和比例很重要
- 推荐短边至少768像素
- 统一比例（如4:3）让训练效果更好

**如何裁剪？**
1. 在"裁剪比例"下拉菜单选择比例
   - 4:3（推荐，适合大多数建筑照片）
   - 16:9（宽屏）
   - 1:1（正方形）
   - 或选择"自定义比例"输入自己的数值
2. 会出现一个**绿色框**，这就是裁剪区域
3. 拖动绿色框的**边缘和角落**调整大小
4. 拖动绿色框的**中间**移动位置
5. 调整好后，点击"✂️ 应用裁剪"按钮

**💡 智能提示：**
- 如果裁剪后图片太小（短边<768像素），会弹出警告窗口
- 三个选择：
  - ✅ **继续应用**：确认使用这个裁剪
  - 🔄 **重新裁剪**：回去调整裁剪区域（选择更大的范围）
  - ⏭️ **下一张**：跳过这张图片，处理下一张

#### **第4步：添加标签（三种方式）**

**方式1：人工选择标签（中间栏）**
- 中间栏有两大类标签：
  - **空间感知（人可停留）**：无灰空间和空间边界处理标签
    - 例如：曲直形态对比、斜线、锐角等
  - **界面感知（人可看见）**：通透程度和开口密度标签
    - 例如：极高界面透明度、悬挑/前伸等
- 鼠标悬停在标签上可以看到详细说明
- 勾选你觉得符合的标签（可以多选）
- 选中的标签会自动显示在右侧"最终标签"区域

**方式2：AI自动生成标签（右侧）**
1. 需要先设置API（如果没有可以跳过）
   - 在右侧找到"API配置"区域
   - 输入你的OpenAI API Key
   - 确认 API URL 和模型名称
   - 点击"💾 保存配置"
2. 点击"✨ 生成"按钮
3. 等待5-15秒（会显示"⏳ 生成中"）
4. AI只会从 11 个标准标签中选择，并自动添加到"最终标签"区域

**方式3：手动编辑标签**
- 在"最终标签"文本框里可以直接输入或修改
- 多个标签用英文逗号分隔
- 例如：`street_vitality, facade_setback, high_transparency`

#### **第5步：设置输出文件夹（只需设置一次）**
1. 点击右侧的"📁 选择输出文件夹"按钮
2. 选择你想保存结果的位置
3. 会弹出提示，告诉你文件会保存到哪些子文件夹
4. 这个设置会保持，后续图片都会保存到这里

**输出文件夹结构：**
```
你选择的文件夹/
├── spatial_perception_only/  # 只选了空间感知标签的图片
├── interface_perception_only/ # 只选了界面感知标签的图片
├── spatial_interface_both/   # 两种标签都选了的图片
├── other/           # 其他情况
├── no_tags/         # 没有选标签的图片
└── statistics/      # 📊 统计报告（自动生成）
```

#### **第6步：保存**
- 检查"最终标签"区域的内容是否正确
- 点击"💾 保存 & 下一张 →"按钮
- 工具会：
  1. 保存图片（.png格式）
  2. 保存标签（.txt文件，和图片同名）
  3. 自动跳到下一张图片
  4. 更新统计数据

#### **第7步：继续处理下一张**
- 重复步骤3-6
- 可以用键盘左右方向键切换图片
- 可以用 `Ctrl+S` 快速保存
- 可以用 `Ctrl+Enter` 快速保存并下一张

#### **第8步：查看统计报告（全部完成后）**
1. 打开你设置的输出文件夹
2. 进入 `statistics` 子文件夹
3. 打开 `labeling_report.txt` 文件
4. 可以看到：
   - 处理了多少张图片
   - 每个标签用了多少次
   - 各个分类文件夹有多少图片
   - 标签使用的百分比统计

## 💡 使用技巧

### 提高效率
1. **快捷键**：
   - `←` `→` 切换图片
   - `Ctrl+S` 保存
   - `Ctrl+Enter` 保存并下一张
2. **批量处理**：选好输出文件夹后，可以连续标注多张
3. **先裁剪**：养成习惯，每张图先裁剪再标注

### 保证质量
1. **注意分辨率**：看到分辨率警告时，尽量重新裁剪
2. **仔细选标签**：鼠标悬停查看标签说明，理解后再选
3. **检查最终标签**：保存前检查标签区域的内容
4. **定期备份**：完成一批后，复制输出文件夹备份

### 处理问题
1. **裁剪框看不见**：选择非"原始"模式，会自动显示
2. **AI生成慢**：正常现象，网络不好时可能需要20-30秒
3. **保存失败**：检查输出文件夹路径是否正确，是否有写入权限
4. **程序卡住**：关闭重新启动，不会丢失之前保存的数据

## ❓ 常见问题快速解决

### Windows问题

**Q: 双击start.bat闪退**
- A: 右键点击 start.bat → "编辑"，看看里面有没有错误提示
- A: 或者打开cmd，手动运行命令，可以看到错误信息

**Q: 提示"pip不是内部命令"**
- A: Python安装不完整，重新安装Python，务必勾选"Add Python to PATH"

**Q: 提示缺少某个库**
- A: 打开cmd，运行：`pip install -r requirements.txt`

### Mac问题

**Q: 提示"command not found"**
- A: 确认Python已安装，使用 `python3` 而不是 `python`
- A: 运行：`which python3` 查看Python是否安装

**Q: 终端里输入命令后没反应**
- A: 确保按了回车键
- A: 如果还没反应，尝试关闭终端重新打开

**Q: 提示"Permission denied"**
- A: 运行：`chmod +x run.sh` 给脚本添加执行权限
- A: 或者用：`sudo ./run.sh` （需要输入密码）

### 通用问题

**Q: 界面显示不全或很小**
- A: 拖动窗口边缘放大窗口
- A: 或点击窗口最大化按钮

**Q: 图片显示不出来**
- A: 确认图片格式是支持的（jpg/png/jpeg等）
- A: 确认图片文件没有损坏
- A: 尝试用其他图片测试

**Q: AI标注一直转圈不出结果**
- A: 检查网络连接
- A: 检查API Key是否正确
- A: 在API配置中增加"超时时间"数值

**Q: 保存时提示错误**
- A: 确认已选择输出文件夹
- A: 确认有写入权限
- A: 确认磁盘空间充足

**Q: 找不到统计报告**
- A: 统计报告在：输出文件夹/statistics/labeling_report.txt
- A: 需要至少保存一张图片后才会生成

## 🎯 使用建议

### 第一次使用
1. 先用3-5张图片测试完整流程
2. 熟悉界面和各个按钮的功能
3. 试试不同的裁剪比例
4. 理解标签的含义

### 正式标注
1. 准备好所有图片（建议分批处理）
2. 确保图片质量足够好
3. 养成"裁剪-标注-保存"的习惯
4. 定期查看统计报告，了解标签分布

### 数据管理
1. 每完成一批，备份输出文件夹
2. 统计报告可以帮你了解标注进度
3. 不同项目使用不同的输出文件夹
4. 保留原始图片，不要删除
