📌 首次使用必读（2分钟快速上手）

┌─────────────────────────────────────────────────────────────────┐
│  🪟 Windows 用户 - 两步启动                                      │
└─────────────────────────────────────────────────────────────────┘

  ✅ 第1步：确认Python已安装
    • 按 Win+R → 输入 cmd → 输入 python --version
    • 需要 Python 3.8 或更高版本
    • 没有？→ 下载安装：https://www.python.org/downloads/
      ⚠️ 安装时必须勾选 "Add Python to PATH"

  ✅ 第2步：启动程序
    • 双击 start.bat 文件
    • 首次运行会自动安装依赖（1-3分钟）
    • 等待程序窗口弹出

  ✨ 完成！开始标注吧


┌─────────────────────────────────────────────────────────────────┐
│  🍎 Mac 用户 - 三步启动                                          │
└─────────────────────────────────────────────────────────────────┘

  ✅ 第1步：确认Python已安装
    • 打开"终端" → 输入 python3 --version
    • 需要 Python 3.8 或更高版本
    • 没有？→ 下载安装：https://www.python.org/downloads/

  ✅ 第2步：进入工具目录
    • 在终端输入：cd 空格
    • 把工具文件夹拖到终端窗口
    • 按回车

  ✅ 第3步：启动程序
    • 输入：chmod +x run.sh （仅第一次）
    • 输入：./run.sh
    • 等待程序窗口弹出

  ✨ 完成！开始标注吧


═══════════════════════════════════════════════════════════════════
  💡 5步完成标注
═══════════════════════════════════════════════════════════════════

  1️⃣ 加载图片
     点击"📁 选择图片文件夹" → 选择你的图片文件夹

  2️⃣ 裁剪图片（推荐）
     选择比例（推荐4:3） → 拖动绿色框 → 点击"✂️ 应用裁剪"
     💡 如果提示分辨率过低，选择"重新裁剪"调整更大区域

  3️⃣ 选择标签
     中间栏勾选标签 或 右侧点击"✨ 生成"AI标签

  4️⃣ 设置输出
     点击"📁 选择输出文件夹"（只需设置一次）

  5️⃣ 保存
     点击"💾 保存 & 下一张 →"继续处理

  ❓ 常见问题
═══════════════════════════════════════════════════════════════════

  Q: 双击后闪退/没反应？
  A: • Windows：右键 start.bat → "编辑" 查看错误
     • Mac：在终端运行可以看到错误信息
     • 确认Python已正确安装

  Q: 提示"找不到Python"？
  A: 重新安装Python，记得勾选"Add Python to PATH"

  Q: AI生成一直转圈？
  A: • 检查网络连接
     • 检查API Key是否正确
     • 在API配置中增加超时时间

  Q: 统计报告在哪里？
  A: 输出文件夹/statistics/labeling_report.txt
     至少保存一张图片后才会生成

  Q: 裁剪后提示分辨率过低？
  A: 这是质量检查，建议选择"重新裁剪"
     尝试裁剪更大的区域以提高分辨率
