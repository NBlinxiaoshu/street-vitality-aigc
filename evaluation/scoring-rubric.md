# 生成效果评分口径

对 Base 与 LoRA 生成结果隐藏模型来源后进行配对盲评。每项采用 1-5 分制。

## 1. 提示词遵循度

- 1：核心空间变量缺失或与提示词相反。
- 3：主要变量基本出现，但数量、程度或组合存在偏差。
- 5：空间设计手法、通透度和开口密度均准确响应。

## 2. 空间真实性

- 1：建筑、道路、入口或灰空间关系明显不成立。
- 3：整体可理解，但存在局部尺度、透视或连接问题。
- 5：空间尺度、透视、结构和使用关系自然可信。

## 3. 色彩与材质合理性

- 1：色彩、光影或材质明显失真，影响空间判断。
- 3：整体协调，但存在局部纹理破碎、反光或材质混乱。
- 5：色彩、光影和材质统一自然，无明显生成瑕疵。

## 4. 设计可用性

- 1：无法作为空间研究或方案讨论材料。
- 3：可表达主要意图，但需要明显修改。
- 5：空间意图清晰，可直接用于方案比较或问卷刺激材料。

## 汇总方式

```text
单张综合分 = 四项得分之和 / 4
模型综合分 = 45 个情境综合分的均值
相对提升率 = (LoRA 综合分 - Base 综合分) / Base 综合分 x 100%
```

建议至少由两名评审独立评分，并报告评审一致性。争议样本应单独记录，而不是直接删除。
