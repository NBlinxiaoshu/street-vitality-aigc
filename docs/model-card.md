# 模型卡

## 基座与训练方式

- Base：Stable Diffusion XL 1.0
- Adapter：LoRA
- 训练模块：UNet only
- 数据规模：288 张图文对
- 训练周期：16 Epoch
- 输出形式：LoRA `.safetensors` 权重（未包含在仓库）

## 目标能力

提升模型对街道空间设计手法、首层界面通透度和沿街开口密度的响应能力，减少以人群、灯光和高饱和度代替空间活力的捷径。

## 评测

使用 5 x 3 x 3 全因子提示词矩阵构建 45 个情境，并从提示词遵循度、空间真实性、色彩与材质合理性、设计可用性四项进行 Base/LoRA 配对比较。

## 不适用场景

- 不用于真实工程安全、结构或规范审查；
- 不应把生成结果视为对街道活力的客观测量；
- 不适合在缺少人工复核时自动替代设计决策；
- 不应用于推断个体行为、身份或社会属性。

## 已知风险

- 小数据导致构图或风格过拟合；
- 提示词标签可能存在英文语义偏差；
- 生成图可能出现透视、结构、材质和尺度错误；
- 研究结论依赖特定实验材料与受试样本，不能直接外推到所有城市环境。
