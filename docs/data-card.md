# 数据卡

## 用途

数据用于 SDXL LoRA 领域适配，使模型学习街道首层界面中与停留、进入和视觉连接相关的空间特征。

## 规模与形式

- 288 张候选街道空间图像、286 个 TXT Caption；
- 文件名审计得到 285 组严格同名的图文对。另有 1 组疑似因文件名附带时间戳而未匹配，2 张副本图像缺少 Caption；
- 训练分辨率目标为 1024 x 1024，并启用多尺度 Bucket。

## 标签生成

GPT-4V 依据 11 个封闭标签进行初标，人工逐张复核后输出训练文件。视觉模型的输出不被视为真值。

## 清洗标准

- 主体应包含可判断的街道首层界面；
- 排除严重遮挡、极端透视和无法判断空间边界的图像；
- 裁剪后短边低于 768 px 时需复核；
- 控制视角与尺度，同时保留必要的场景多样性；
- 避免把人群数量、灯光和饱和度作为活力标签的直接依据。

## 公开限制

原始图片的来源和授权状态需要逐项确认，因此本仓库默认不包含完整训练数据。公开数据前应：

1. 确认图片版权和使用许可；
2. 移除个人信息及可识别敏感信息；
3. 记录数据来源、授权范围和删除机制；
4. 提供可公开的最小示例集，而非直接上传全部原图。

仓库仅抽取 5 组代表性训练图像作为格式示例，见 [`../examples/training-samples/`](../examples/training-samples/)。这些示例不代表完整数据分布，公开前仍需逐项确认图片来源、版权与使用范围。

## 数据完整性审计

训练前应先修复以下文件关系，再以训练日志确认实际读取数量：

- `45bfb1b820248de3db2a828b14efc43a 13.09.22.png` 与 `45bfb1b820248de3db2a828b14efc43a.txt` 疑似同一组，但基名不一致；
- `aee8ca9619b3028aecd24cdd806b1304_副本.png` 缺少同名 Caption；
- `aee8ca9619b3028aecd24cdd806b1304_副本2.png` 缺少同名 Caption。

## 已知偏差

- 数据量较小；
- 可能偏向特定城市、建筑风格与摄影视角；
- 标签包含专业判断，标注者间一致性尚未系统报告；
- 英文 Caption 可能引入概念翻译偏差。
